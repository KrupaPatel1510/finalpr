COVID-19 Data Analysis and Visualization

📌 Project Overview

The COVID-19 Data Analysis and Visualization project analyzes the spread of COVID-19 over time. It examines trends in total cases, deaths, and vaccinations across different countries using Python.

The project uses data analysis and visualization techniques to understand the impact of the pandemic.

🎯 Objectives

- Analyze COVID-19 cases over time.
- Study the trends in COVID-19 deaths.
- Analyze vaccination data.
- Compare COVID-19 data across countries.
- Visualize data using graphs and charts.
- Practice data analysis using Python.

🛠️ Technologies Used

- Python – Programming language.
- Pandas – Data manipulation and analysis.
- Matplotlib – Data visualization.
- Seaborn – Statistical data visualization.

📂 Dataset

The project uses COVID-19 data from Our World in Data.

Dataset link: https://ourworldindata.org/covid-cases

The dataset includes information such as:

- Date
- Country name
- Total COVID-19 cases
- Total COVID-19 deaths
- Total vaccinations

📋 Requirements

Install Python and the required libraries before running the project.

pip install pandas matplotlib seaborn

🚀 How to Run the Project

1. Download or clone the project.
2. Download the COVID-19 dataset.
3. Save the CSV file as "covid_data.csv".
4. Place the CSV file in the same folder as the Python program.
5. Install the required libraries.
6. Run the Python program.

python covid_analysis.py

7. Enter the country name when prompted.
8. View the COVID-19 data and graphs.

📊 Features

- Loads COVID-19 data from a CSV file.
- Displays the first five records.
- Allows users to select a country.
- Displays COVID-19 case trends.
- Displays COVID-19 death trends.
- Shows the maximum recorded total cases and deaths.
- Generates line graphs using Matplotlib.

📈 Visualizations

The project generates the following graphs:

1. COVID-19 Cases Over Time: Shows changes in total reported cases.
2. COVID-19 Deaths Over Time: Shows changes in total reported deaths.
